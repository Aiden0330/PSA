## 1 · 安全关键缺陷(2 项)

### F-1(最高)`warn-gas-h2` / `B_GAS_DET` —— H₂ 单参量的"预警提前量"被第三方实测证伪

- **库中原状**:`warn-gas-h2` pfd=0.07(即 93% 有效),note 称"H₂ 在热失控临界前 <1 min
  出现,提前量短"。`B_GAS_DET`(H₂/CO)pfd=0.07,无 note。
- **原文核验**:Torres-Castro et al., *J. Electrochem. Soc.* **171** 020520 (2024),
  DOI [10.1149/1945-7111/ad2440](https://iopscience.iop.org/article/10.1149/1945-7111/ad2440)
  (Sandia 对商用探测器的第三方实测)给出的 H₂ 热导通道提前量为 **负值**:过温工况
  **−0.4 min**、过充工况 **−0.2 min** —— 即报警发生在热失控**之后**。
- **危害方向**:非保守。序列若建模为"气体预警 → 人工/自动干预阻断 TR",用 0.07 会把一条
  **实际不存在**的成功路径按 93% 记入,直接低估终态频率。
- **影响面(评审量化)**:两条**未被任何内置场景引用**(`scenarios.json` 五场景与
  `tr_model_data.json` 的屏障链均无) ⇒ 内置定量零影响。但**防护不能只放 note**:选用路径
  `EtInspector.tsx:193` 的 LibPicker 只呈现 `{id, name}`,`eventtree.ts:296` `addBarrierFromLib`
  只快照 name/pfd/citation —— **note、category、grade 都不随节点走**。用户看到的全部语义就是
  条目名,而原名"氢气探测**预警**"本身就在宣称被证伪的功能。误用量级:该分支下游终态频率最多
  低估 **1/0.07 ≈ 14×**。
- **处置**:①**限制写进 `name`**(唯一可见语义面)——
  `氢气探测(H₂ 单参量)—— TR 后确认/联动,非 TR 前预警`、
  `气体探测(H₂/CO)—— 探测可靠性口径,非 TR 前预警`;② 不改 0.07:论文显示 H₂ 通道**确实探到了
  气体,只是晚**(1s4p +0.1、2s4p +0.4 min),作"TR 后确认 / NFPA 69 抑爆联动触发"的探测可靠性
  未被证伪,改成 ~1.0 会连合法用途一起杀掉且与论文数据矛盾;③ note 给出替代条目并**收窄措辞**——
  证据边界是 NMC 软包 + 热导式传感器 + 过温/过充两工况,外推 LFP/枝晶失效(有 H₂ 早现文献)属默认
  保守,故由"绝不可"改为"无项目级实证不得取信"(全称否定超出单篇两工况的证据范围,监管答辩会被
  厂商反证)。

### 4.1 `IE_FLEET_2025` 撤销(评审 S2)

初稿以"EPRI 2018→2025 失效率降 99%"折算出 3e-5 /unit·yr 作现代机队基准。评审逐项拆穿:

1. **算术自相矛盾**:99% 是 **100×**,note 却写"降约 27×",两者差 4× 被当成同一件事;
2. **输入被误引**:note 称按 `IE_FLEET_STAT`(**1e-3 量级**)折减,该条实际值是 **5e-4**,
   5e-4 ÷ 27–30 = 1.7–1.9e-5,**凑不出 3e-5** —— 推导链在库内无法复现;
3. **二次折减**:99% 以 2018 为基线,而 `IE_FLEET_STAT` 是 2017–2024 暴露加权累计均值,
   其暴露主体本就在近年、已反映改进,再除全程降幅是重复折减;
4. **与 EPRI 自家结论冲突**:"72% 失效发生于建设/调试/头两年"意味着**最新投运群组承担超额
   失效**,给 2024–25 群组一个低于机队均值近一个量级的基准是结构性矛盾,方向**非保守**;
5. **schema 缺陷**(评审顺手抓到的真 bug):该条用 `"name"`,其余 7 条 IE 用 `"label"`,
   而 `ReferenceLibrary.tsx:29` 初因列渲染 `label` ⇒ **该行初因名在 UI 里是空白**;
   测试不查 `label`,664 全绿也拦不住。

**处置:撤销该条**,而非改值。理由:99% 是**相对趋势**,无公开绝对锚点可换算成 /unit·yr;
按评审给的内部自洽算法可落到 ~1.5e-4–3e-4,但那仍是我选锚点的产物。一个**推导不可复现的
基准值**在监管面向的库里是负资产 —— 按本库自己的规矩(没有出处的数值不入库)应当不入。
已核验的 2025 趋势事实并入 `IE_FLEET_STAT` note,连同撤销原因一并留痕。

### 4.2 新增条目的组合口径(评审 S4 更正后)

- 两条"就绪性"只表征**需求时刻不就绪**。初稿写的"与既有灭火有效性条目串联"**是错的**:
  `B_SUPPRESS`(LOPA 通用 IPL)与 `sup-sprinkler-wet-nfpa`(NFPA 92%×97%,失效首因即阀门被关)
  都是**全含**口径 —— 不可用性已在其中,再串 0.26 是把不可用性计两遍,完整 PFD 被推到 ~0.33,
  约 **3× 失真**(方向保守,但扭曲重要度排序与加固优先级,监管答辩同样站不住)。
  **正确配对**是就绪性 ⊕ **条件有效性**(`B_SUPPRESS` note 内已有的 η≈0.953,即 0.26 ⊕ 0.047)。
