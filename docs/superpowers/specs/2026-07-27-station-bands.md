# 规格:站级不确定带(ST-6)——钉扎案例分位的同分位合成

上游:`2026-07-27-station-model.md`(v1 点值)。铁律不变:**绝不现算**——站级只读
产品钉扎案例已存的 `results.bands`(逐后果箱 p05/p50/p95),不重跑任何 MC。

## 1. 语义:同分位代入 = 全联动包络(单调性定理保证自洽)

站级五指标(any/ge2/ge5/ge_row/offsite)对每个舱级频率输入**单调递增**。因此把
各产品尾和的 q 分位代入公式,得到的是**认知全联动假设下输出的精确 q 分位**——
不是拼凑,是有定理的包络:

- **同产品跨舱**:同一钉扎案例喂所有该产品舱 ⇒ 全联动**精确**(同一数据源,
  SOKC 就该如此)。
- **跨产品**:同分位联动是**申报的保守包络**(p95 同高、p05 同低 ⇒ 带更宽;
  独立合成需要分布,钉扎案例只载 3 个分位——禁现算,故取包络并申报)。
- **箱内尾和**:尾和 q 分位 = Σ 各箱 band[q](同案例各箱出自同一 MC,全联动
  近似;p95 侧为上包络)。
- **站级参数**(边概率/站级屏障 PFD/围栏概率)以**点值**参与,不贡献带宽
  (待站级参数不确定性,入申报)。

带序不倒挂:输入带有序(校验强制)+ 公式单调 ⇒ 输出 p05 ≤ p50 ≤ p95 恒成立。

## 2. 尾和分位规则(逐产品)

对箱集 K(f:C3..C5;f4:C4..C5),分位 q ∈ {p05,p50,p95}:

```
tail_q = Σ_{k∈K} ( bands[k][q]  若案例 bands 含 k
                   cons[k]      否则(点值退化带) )
```

- 点值为 0 且无带的箱:贡献 0,不记账(无信息缺失)。
- **点值 >0 且无带的箱:以点值参与全部分位 + 记入 band_notes**(部分带,响亮
  申报,不静默)。
- `band_status`(每产品):`full` = 参与箱(点值>0)全部有带;`partial` = 部分
  有;`none` = 全无。全产品 `none` ⇒ 站级 `bands = null` + band_notes 说明
  (空缺可见,不静默省略)。p50 有带用带(MC 中位数 ≠ 解析点值,不混)。

## 3. 校验(422 响亮)

产品案例 bands 中出现的 C3/C4/C5 箱:数值、≥0、p05 ≤ p50 ≤ p95,violation 点名
产品与箱(倒挂带喂出倒挂站级带 = 静默胡说)。其他箱(C1/C2)不参与不校验。

## 4. 响应形状增量(点值通道逐位不变——锁在案)

```
quantify → { metrics: …(逐位同 v1), bands: {any,ge2,ge5,ge_row,offsite:
             {p05,p50,p95}} | null, band_notes: [str],
             products[]: += band_status, f_band: {p05,p50,p95}|null }
```

实现形:抽 `_eval_metrics(doc, fmap)`(fmap = 产品键→(f,f4))单代码路径,点值
调用即原算式原顺序(逐位不变),带调用同函数换 fmap——点/带永不分叉。

## 5. 出口

- **报告 docx**:钉扎案例带 bands 时,KPI 表增 P05/P50/P95 三列 + band_notes
  段;旧钉扎案例(无带)按原版式渲染(向后兼容,不 404)。
- **站页 UI**:KPI 卡点值下方细行 `p05 – p95`(p50 括注);检视器产品块显示
  band_status;band_notes 进不可隐藏申报区。
