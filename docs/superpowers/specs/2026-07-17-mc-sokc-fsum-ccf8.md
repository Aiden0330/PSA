## S-A · 单树 MC 按参数 ref 联合抽样(SOKC)

**病**:`event_tree_uncertainty` 按底事件**节点**独立抽(uncertainty.py:44 逐 bb draw),
同一库参数挂多个冗余通道时认知源被当独立 → 上分位非保守收窄(实测 AND 同 ref 对:p95
0.047 vs 正确 0.09,1.9×);聚合通道却已按 ref 联合抽——同工具两口径。

**改**:与 `aggregate_event_tree_uncertainty` 同法则——refs 排序、单一 RNG 流、每迭代抽
一个按 ref 的联合向量,节点 q = sampled[ref_of[bb]]。截断维持 [0,1](普通路径无频率底
事件;频率量纲分流属集成 MC 规格 S2)。

**锚点**:A1 单树 ≡ 聚合单树(同 seed 逐位,p05/p50/p95 × C1–C5——两条代码路径一个语义);
A2 判别例 AND(A1,A2) 同 ref(.1, EF3, N=4000, seed7)p95/λ ∈ [0.07,0.12](现 0.047 → 红);
A3 独立 ref 模型语义不变但 RNG 流变 → banked A7 特征化锁**重定基**(新冻结值,迁移注记)。

**病**:quantify 按树序累加、报告按频率降序累加(浮点不可结合)→ 同模型两表面末位差

则(fsum 开销 ≪ 逐序列 BDD 求值;向量化实现须保持该口径——见集成 MC 规格 Opus 简报)。

**锚点**:B1 构造大小混量级模型(pfd 0.5/1e-16/1e-16),quantify C2 ==
