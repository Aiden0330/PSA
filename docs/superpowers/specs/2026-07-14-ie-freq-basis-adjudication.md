# 初因频率口径统一(open-Q4 裁决稿)

*2026-07-14 · 状态:**裁决稿,domain-reviewer 评审中** · 源起:4c2 模板迁移评审
open-Q4(模板 IE 频率与场景库口径差,ROADMAP 已两处注明)*

## 1 · 问题

同一初因在两处数值不同口径:**7 个预置模板**的 IE 频率按前代工具的
**10 MWh 系统级**推导;**场景库 / 参考库 IE 条目**(CFR_*)为**舱级先验**
(unit=/yr,语义为单舱)。用户跨源引用或对比时可错 1–2 个量级;
两处都各自有出处,数值本身都"对",错的是混用。

## 2 · 裁决(推荐)

- **canonical 口径 = 舱级**(单舱·年)。理由:本工具事件树的建模单元即舱
  (C1–C5 后果以舱为演化单元;屏障链是舱级纵深防御);参考库 IE 条目已按此
  治理(unit 强制 + 推导链锁测)。站级/系统级数字属**项目层换算**
  (×舱数,或按容量比),换算必须显式出现在推导注记,不得静默。
- **模板值不改**(它们的出处是前代工具语境,改值=篡改证据):每个模板 IE
  频率追加**口径注记**——"10 MWh 系统级(≈N 舱)推导;舱级换算 ÷N ≈ …,
  引用参考库 CFR_* 舱级先验请勿叠加"。建库横幅已有"替换取值"提醒,追加
  口径一句。
- **不新增结构化 basis 字段**(最小改动原则):参考库 IE 的 unit+note 锁测
  已强制推导链;模板侧以同等注记补齐;canonical schema 不动(避免为口径
  差引入 schema 演进)。TD-001 §7 单位纪律段补一句"系统级↔舱级换算须显式"。
- **验收绊线**:test_library 增一条——模板(scenario library 侧)IE 注记
  必须含口径关键词(「舱级」或「系统级」+换算说明),防新模板再次静默混口径。
