## 1 · 问题

分析案例覆盖导出/运行当时的**单棵事件树**;组合总览据此比较的是"各项目最近钉扎
场景",非项目全部风险。多 IE 项目被系统性低估。现状靠披露(场景列+口径脚注)
防误读,不解决口径本身。

## 2 · 裁决:新增「勾选集聚合」导出模式

- **触发**:报告导出与不确定性运行新增可选 `scope="checked_set"`(默认仍
  `single`,零扰动)。聚合 = 当前勾选的全部 ETA 页签。

### 2.1 点估计口径(精确,但前提必须显式)

聚合后果频率 = 各树同级后果频率**逐级求和**。概率论论证:后果级 c 的量是
E[年到达次数](率语义),E[ΣN]=ΣE[N] 对任意相关结构恒成立——共享底事件/参数
只影响方差不影响均值。**"精确"依赖三个建模前提**(评审 A2,违反即双计或无意义量):

1. **初因事件互斥(MECE)**:各勾选树计数不相交的物理事件集。本仓库默认内容自带
   两类违例,页脚必须披露:①重复建模(`bess-thermal-runaway` 与 `bess-ie-isc`
   同为电芯内短派生,同时勾选=同一初因计两次);②重叠建模(`IE_EXT_FIRE` 语义为
   "邻舱辐射引燃本舱"——它是内短树 C4/C5 后果的子集,默认 5 场景全勾时多舱蔓延
   被计两次)。方向恒为高估(保守),但须可见。LOPA 模板的双树拆分(探测成功/失败
   链)则是**不相交分解,求和正确且必须**——三类情形都写进页脚免责句。
2. **同一频率基准**:各树 IE 频率须同口径(舱级 canonical,见稿 B)。逐树分解表
   带各树基准注记。
3. **后果级语义对齐**:聚合按 canonical 级号(C1–C5)对齐;模板可覆盖
   outcomeNames——非标准终态命名的树在 per_tree 分解中标注。

**率语义围栏**(评审 Q1 补):"精确"仅对率(/yr 期望)成立;若未来引入
1−exp(−fT) 类"期内至少一次概率"口径,逐级求和退化为**保守上界**,须另行声明。

### 2.2 不确定性聚合(评审 A1,阻断级修订)

"同一抽样"在旧稿中不可执行:canonical 参数按树命名空间隔离(`et:{key}/param:*`),
**当前数据模型不存在跨树参数同一性**。裁决采用推荐修法:

- **跨树认知参数同一性 = 同 ref 名**(项目全局命名空间;与 RiskSpectrum
  "同名即同事件"的行业语义一致,是树内既有原则的自然外推)。
- 每次 MC 迭代抽**一个联合参数向量**:同 ref 名参数共享同一次抽样,施加到全部
  勾选树,逐树求值再逐迭代相加,得聚合分位带。
- 禁止两种错误实现:①同 seed 逐树各跑再相加(RNG 流套在各树底事件枚举序上,
  产生由字典序决定的伪耦合,不可辩护);②各树独立抽样再相加(共享数据源参数被当
  独立 → 聚合上分位**被压窄,静默非保守**——NUREG-1855 SOKC 标准情形)。
- 页脚继承性披露两句:①"IE 频率按定值处理,其不确定性未入带"(初因频率是领域
  最大不确定性来源);②"分位数不可加:逐树分解为点估计,Σ逐树 p95 ≠ 聚合 p95"。

### 2.3 钉扎形状(评审核实充分,维持)

一次 auto-pin 产生一个案例:`kind="report"|"uncertainty"`,
`settings.scope="checked_set"`,`settings.scenarios=[{key,name},...]`,
`results.consequences` 聚合值 + `results.per_tree=[{key,name,consequences}]`。
**不改 DB schema**。单个 version hash 已覆盖全部勾选树内容(payload 整体规范化),
证据链"聚合数字→案例→版本哈希→各树→参数→出处"完整。

### 2.4 呈现与消费(评审 A3:scope 标识全表面)

凡呈现聚合值处必随 scope 标识:**报告正文 C1–C5 表标题**(「勾选集聚合(n 树)」,
不能只靠页脚)、**CSV 导出元数据行**、**案例列表**、**组合总览徽章**(「聚合 n 树」
替代场景名)+ 基准注记。矩阵落格处徽章同现(求和后频率会上移频带,聚合行与单场景
行落格天然不同)。组合总览"最新案例"语义**维持 latest-wins,不偏好 checked_set**
(偏好会把钉在旧模型版本上的过期聚合当现状——比口径回落更糟,与 review_state
锚最新版同理);组合总览页脚加"各行案例口径可能不同,比较以徽章为准"。
旧案例(无 scope)语义 = single,零迁移。

## 3 · 锚点(实现前先落,失败测试先行)

1. **均值锚**:树 1(f=1e-3,屏障 0.1)→ C1=9e-4,C2=1e-4;树 2(f=2e-3,屏障 0.2)
   → C1=1.6e-3,C2=4e-4;聚合 C1=2.5e-3、C2=5e-4,Σ=3e-3=Σf(守恒跨树保持)。
2. **共享参数均值不变锁**:两树同 ref 名 PFD——聚合均值与独立情形同值(期望线性)。
3. **共享参数分位锚**(评审 A1 新增,方差行为的判据):两树 C2 = f·θ,
   f₁=1e-3、f₂=2e-3,θ 同 ref 名(median 0.1,EF=3 ⇒ p95=0.3):联合抽样下
   聚合 C2 p95 = 3e-3×0.3 = **9e-4**;独立抽样严格小于此值(这就是实现对错的
   判据);两种方式均值同值。
