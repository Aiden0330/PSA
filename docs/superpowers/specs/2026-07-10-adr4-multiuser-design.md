## 决策记录(用户访谈,2026-07-10)

- **D-P5-1 协作语义 = 共享项目 + 评审流**(否决实时并发编辑)。多人访问同一项目库、
  同一时间一人编辑,重心在评审/签发工作流。**CRDT(Yjs/Loro)整体移出 Phase 5**
  (账本保留为 Phase 6 选项);盲区探针 P4 取消。与 RiskSpectrum 团队版同属库模型,
  符合监管场景习惯。
- **D-P5-2 部署与身份 = 公司内网 + 本地账户**。用户名 + 口令(argon2id 哈希)+
  HttpOnly 会话 cookie;零外部依赖,隔离网可用;架构预留 OIDC/SSO 叠加点
  (认证抽象为 provider 接口,本地账户是第一个实现)。
- **D-P5-3 角色 = 小团队三角色,项目全局可见**:管理员(账户/项目管理)、
  分析员(建模/量化/导报告)、评审人(只读 + 评论 + 签发)。约 3–10 人;
  不做项目级 ACL(简化权限模型;将来若需多客户隔离再立 ADR)。
- **D-P5-4 并发策略 = 乐观保存 + 冲突提示**(否决 check-out 锁)。保存时以
  **内容哈希/父版本比对**检测服务器端前进;冲突弹窗给三条路:查看双方 diff
  (版本对比组件已有)、另存副本、确认覆盖(仍留双方版本——ADR-2 内容寻址保底不丢)。
  无锁登记/忘解锁问题。
- **约束 #0(先立)**:离线单文件与本地免登录模式永久保留且为默认;
  认证是部署开关(`PSA_AUTH=off|local`),多用户为同一存储上的叠加层。

- **D-P5-5 评审/签发 UX = 方向 A 台账签发式**(用户选定 2026-07-12;4 方向 mockup 见
  `docs/design/mockups/2026-07-10-review-{a,b,c,d}.html`,提交 9769dc6)。
  报告页版本台账加签发状态列(草稿/送审中/已签发/退回)+ 版本级评论 + 签发确认弹窗 +
  页脚签发行 + 正式导出门(未签发 → 工作稿水印)。**不做**(留缝待将来):
  元素锚定评论线程(B,评论表可后加 anchor 列)、多项目看板(C,纯 reviews 视图)、
  四级会签栏(D,reviews 可后加 role_slot)。
  硬要求保持:签发动作 = 认证身份 + 时间 + 版本哈希入只增审计,并进报告页脚。
  实施规格:`2026-07-12-phase5-review-signoff-spec.md`。

## 架构草图(叠加层,自下而上不动)

```
现有:psaengine / bess / store.py(版本+审计+案例)/ FastAPI / React 壳
叠加:
  auth 层     accounts 表(argon2id)+ sessions(HttpOnly cookie)+ provider 接口(local→将来 oidc)
              PSA_AUTH=off(默认,现行为)| local(登录墙 + 身份)
  身份贯通    store.actor() → 认证身份(server 模式);audit/cases/ai_drafts/报告页脚的"谁"
  权限        路由级三角色守卫(分析端点=分析员+,签发=评审人+,账户管理=管理员)
  并发        POST /api/saved 携带 base_version_hash;服务器比对 → 409 + 双方版本 id → 前端冲突对话
  评审签发    review 对象(版本冻结引用 + 评论 + 签发记录);形态待 D-P5-5
  客户端      401/403 显式处理(修盲区地雷:认证失败绝不静默转"离线存档");登录页;角色感知 UI
```

## 修复项(无论形态,先行)

1. **api.ts 回退地雷**:区分"网络不可达"(→ localStorage 回退,仅 PSA_AUTH=off 模式)与
   "401/403"(→ 显式登录提示,绝不静默降级)。
2. **actor 身份化**:`store.actor()` 在 server 模式取会话身份;单用户模式沿用 OS 用户(不破坏现有审计)。
3. **CORS 收紧**:server 模式白名单化;本地模式不变。

## 验收(实施期)

- `PSA_AUTH=off`:现全部 246+206 测试与离线单文件行为逐位不变(约束 #0 回归门);
- `PSA_AUTH=local`:未登录 → API 401/前端登录页;三角色路由矩阵测试(分析员不可签发、
  评审人不可改模型、管理员可建账户);会话过期→显式提示不丢编辑(本地草稿暂存);
- 并发:双客户端同项目保存 → 后者 409 → 冲突对话三路径全可走,任何路径零数据丢失
  (版本台账双方可见);
- 证据链:签发/AI 应用/贝叶斯升 A 的审计行携带认证身份;签发进报告页脚;审计只增性质测试仍绿;
- 迁移:单机 `data/projects.db` 导入共享服务器(import 路径)幂等无损。
