## 1. 语义:β 因子共因点燃(fleet 级)

物理依据:同产品全部舱共享固件/OTA 批次/BMS 平台/工艺缺陷——一次共因事件
**同时点燃组内全部成员舱**,绕过蔓延屏障(消防/应急只拦蔓延,不拦点燃)。
这正是 CCF 缺席非保守的原因:多舱指标在 v1 里必须走"点燃×蔓延链×双门",
共因通道一步直达。

- 组 = **单一产品**的舱队(fleet)。跨产品共因(共享水源/同班组)物理上走门
  相关性,**留在申报层**,入值通道为不确定性/SOKC(既定裁决,本件不动)。
- 经典 β 拆分(同产品 ⇒ 成员 f 全同,β 因子精确无泛化问题):
  - 成员舱独立部分 `f_i^I = (1−β)·f`(非成员舱不变);
  - 组共因事件频率 `f_C = β·f`(点燃组内全部成员);`f4` 同拆(`f4_C = β·f4`)。
- **守恒**:点燃事件总频率 Σf_i^I + f_C = m·f − (m−1)·β·f —— 共因把 m 次
  独立起因合并为一次,`any`/`offsite` 微降(物理正确,非漏算),多舱指标大增。

## 3. 公式(v1 记号沿用;Σ_g 只跑 valued 组)

成员集:`member_products` 恰 1 个产品键的全部舱,`member_cabins` 给出时取交集。
记组 g 在排 r 的成员位置集 S_r,m_r=|S_r|,m=Σm_r。

| 指标 | v2 公式 |
|---|---|
| any | `1 − Π_i(1−f_i^I) · Π_g(1−f_C^g)` |
| ge2 | `Σ_i f_i^I·esc_i·G_sup + Σ_g f_C^g`(V-4 保证 m≥2,共因即直达 ≥2,不过门) |
| ge_k(k=5 与 k=排长) | `Σ_排 Σ_i f_i^I·chain_{k,i}·G_sup·G_er + Σ_g Σ_r f_C^g·w_r(k)` |
| offsite | `[1 − Π_i(1−f4_i^I)·Π_g(1−f4_C^g)] · p_fence` |

`w_r(k) = 1{m_r≥k} + 1{0<m_r<k}·G_sup·G_er·P_{S_r}(closure≥k)`;m_r=0 ⇒ 0。
直燃成员不过门(点燃非蔓延);补足到 k 需蔓延 ⇒ 整项过双门(v1 同律)。
排内连片口径不变:跨排成员按排分别计数,不做跨排合并(两排同时 ≥k 计两次,
保守方向,入申报)。

**闭包分布 P_S(closure≥k)**(精确,新纯函数 `closure_ge_k(edges, sources, k)`,
其存在即 banked 探针):边状态无向 Bernoulli(通/不通,概率 = v1 边概率),
受累集 = 与 S 连通的全部舱,P = P(|受累|≥k)。路径图上精确 DP(状态:位置 ×
已计数 × 当前连通块长 × 块内含源;O(n²k))或 n≤20 时 2^{n−1} 枚举——实现自选,
**不许抽样近似**。单源一致律:|S|=1 时左右边集不相交 ⇒ 无向 = 有向,
`closure_ge_k(edges,{i},k) ≡ chain_per_cabin(edges,k)[i]`(锚 R-4)。

**全员制式坍缩律**(锚 R-2):单排全舱同属一组且 m_r≥k ⇒
`ge_k^v2 = (1−β)·ge_k^v1 + β·f`(精确闭式,便于逐位断言)。

## 5. 校验(全部 422 响亮,无静默;V 编号入锚 R-5)

- V-1 `valued` 组:`beta` 必填 ∈[0,1];`basis` 必填非空(**入值必须给依据**,
  数据出处铁律)。
- V-2 `member_products` 恰 1 个且为已定义产品键;≥2 键 ⇒ 422(跨产品入值
  需 α/MGL 泛化,v2 不支持,留申报)。
- V-3 `member_cabins` ⊆ 该产品的舱 id(不存在/产品不符 ⇒ 422 点名)。
- V-4 有效成员数 m ≥ 2(单舱"共因"无意义)。
- V-5 舱最多属 1 个 valued 组(重叠组需 MGL,422)。
- 未 valued 组不校验 beta/basis 之外新增项(申报层宽容,原状)。

## 7. β=0 逐位回归律(锚 R-0)

valued 组 β=0 ⇔ 同文档去掉该组:`(1−0)·f = f` 浮点精确、`f_C = 0` ⇒ 各连乘
因子 `(1−0)=1` 精确、各求和项 `+0.0` 精确、`w_r` 项乘 0 消去 ⇒ 五指标**逐位
相等**(`==`,非 approx)。
