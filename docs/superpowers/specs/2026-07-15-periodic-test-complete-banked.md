## 2 · 规范语义(normative)

三状态 Markov 链 {可用 A、潜伏失效 L、在修 R},自 t=0 全新可用起,按阶段闭式推进。
检验窗 [θ+kτ, θ+kτ+π],k=0,1,…

**状态更新序(= 语义本体,顺序不可换)**:

```
p_exp(r,t)  = 1 − e^{−rt}
p_exp2(μ,λ,t) = P(先 μ 过程完成、再 λ 过程发生,t 内)          # 两级卷积,§3 稳定形
p_ml(p_mu,t)  = p_mu·ω + (1−ω)·p_exp2(μ,λ,t)                    # 修完:ω 坏重启→L;否则 A 后可再潜伏失效

t ≤ θ:q = p_exp(λ,t)                                            # 首检前纯老化
初值:p_fail = p_exp(λ,θ);p_repair = 0;p_avail = 1 − p_fail

检验窗步 p_test(窗长 w, available 旗):
  tr        = p_fail + p_avail·(γ + (1−γ)·p_exp(λ*,w))           # 潜伏池 = 窗前潜伏 + γ 冲击 + 检中 λ* 失效
  p_fail'   = p_repair·p_ml(p_exp(μ,w), w) + (1−σ)·tr            # 修出再失效者【跳过本窗检出】
  p_repair' = (1−p_exp(μ,w))·p_repair + σ·tr                     # σ 检出 → 窗末起修
  p_avail'  = 1 − p_fail' − p_repair' − (available ? 0 : p_avail·(1−γ)·(1−p_exp(λ*,w)))

间隔步 p_period(段长 d):
  p_fail   += p_avail·p_exp(λ,d) + p_repair·p_ml(p_exp(μ,d), d)
  p_repair *= 1 − p_exp(μ,d)
  p_avail   = 1 − p_fail − p_repair

推进:n = int((t−θ)/τ) 个整周期(每周期 p_test(π,True) → p_period(τ−π));
余量 rem = (t−θ) − n·τ:
  rem ≤ π → p_test(rem, available_at_test)                        # 【部分窗也做 σ 检出】
  rem > π → p_test(π,True) → p_period(rem−π)
返回 q(t) = 1 − p_avail(§3 夹持)。
```

**四条语义要点**(评审时逐条对照,MC 三角已验):

1. 修后组件以 **λ**(非 λ*)老化——即使身处检验窗(SCRAM 显式传 `p_exp(λ,π)`)。
2. 修出再失效 / ω 坏重启者**跳过当窗检出**,潜伏至下一窗。
3. **部分窗(t 落在窗内)同样施加 σ 检出**——SCRAM 的部分窗分支调用完整 p_test。
4. `available_at_test` 仅影响「查询时刻落在窗内」的可用性记账:x=False 时,
   带着可用状态进窗且熬过 γ 与 λ* 者按不可用计(修出转可用者不算受试,仍可用)。
   推论(恒等式,评审 D2 界定):x=False 且 rem=0(恰在检验起点)→ **实数域
   q ≡ 1 精确**(代数消项:na = p_repair·(1−ω)·(p_μ−p_exp2),w=0 两因子为 0);
   **浮点域为 1 ulp 内**(随机 rem=0 网格上朴素/稳定式各约 25%/29% 点位得
   0.9999999999999999),不得据此全局短路 return 1.0;锚点 A5 只锁 P1 点位
   (该处双式实测逐位 ==1.0)。t=θ(k=0)不在此恒等式内——t≤θ 分支优先(见 A1b)。
