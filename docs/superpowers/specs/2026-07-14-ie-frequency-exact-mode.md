# 初因频率:逐初因精确模式(Gap 9 核心)

*2026-07-14 · 状态:已实现(engine-reviewer 记录见 §5)· 前置:
`2026-07-13-ie-fault-tree-frequency.md`(Σ-of-MCS 通道与 review F5 保守性更正)*

## 1 · 问题

现行 `fault_tree_frequency` 头条 F = Σ_割集 λ·Πq。**同一初因出现在多个割集**时
(λ·(qA+qB) vs λ·P(A∨B)),Σ 高估;非稀有使能域可**超出物理上界 Σλ**
(初因每年至多按其率发生,无论使能条件多少)。RS/SAPHIRE 同为 Σ 口径——保守方向,
但"频率超过初因率之和"会损害可信度,监管人一眼能看出。

## 2 · 语义(精确模式)

把最小割集按初因分组。初因 i 的**使能析取** E_i = ∨_k (∧_{e∈k\{i}} e),
k 取含 i 的全部最小割集:

    F_exact = Σ_i λ_i · P(E_i),   P(E_i) 由 BDD 精确求值(析取内共享使能精确处理)

精确性条件(与 Σ 口径同一假设集,无新增):初因为独立 Poisson 过程(不同初因同时
发生测度为零 → 跨初因求和精确);使能事件为相互独立的常驻状态,且与初因发生无关。
性质:P(E_i) ≤ 1 ⇒ **F_exact ≤ Σ_i λ_i**(物理上界恢复);
E_i 为单割集或跨初因共享使能时 F_exact = F_sum(锁测);**同一全割集口径
(cutoff=0)下恒有 F_exact ≤ F_sum**。注意(round-1 F2):sum 头条沿用既有
post-cutoff 语义、exact 头条不受 cutoff 影响,带 cutoff 同屏对比两头条可出现
exact > sum(锚点 A + cutoff=0.065:sum=0.070 < exact=0.088)——非矛盾,是口径差,
文档四处声明均已加限定。

特例:{i} 单独成最小割集 ⇒(最小性)不存在其他含 i 的割集 ⇒ P(E_i)=1。

## 3 · 手算锚点(测试逐一锁定)

| 场景 | 树 | 参数 | F_sum | F_exact |
|---|---|---|---|---|
| A 共享初因·非稀有 | OR(AND(I,A), AND(I,B)) | λ=0.1;qA=0.6, qB=0.7 | 0.13(**>λ,越界示范**) | 0.1×(1−0.4×0.3)=**0.088** |
| B 跨初因共享使能 | OR(AND(I1,A), AND(I2,A)) | λ1=0.02, λ2=0.03;qA=0.5 | 0.025 | **0.025**(相等) |
| C 单初因裸割集 | OR(I, AND(I2,B)) | λ=1e-3, λ2=2e-3;qB=0.4 | 1.8e-3 | **1.8e-3**(P(E_I)=1) |
| D 初因内三割集重叠 | OR(AND(I,A,B), AND(I,B,C), AND(I,C)) | λ=0.05;q=0.3/0.4/0.5 | 0.05×(0.12+0.2+0.5)=0.041 | 0.05×P(AB∨C)=0.05×0.56=**0.028**({B,C} 被 {C} 吸收) |

D 手算(round-1 F1 更正:初稿给 0.0315,分解双计——条件在 ¬C 上时割集 B∧C 恒假,
第二项只剩 P(¬C)·P(A∧B)):最小化后 I 的使能集为 {A,B} 与 {C};互斥分解
P(AB∨C) = P(C) + P(¬C)·P(A∧B) = 0.5 + 0.5×0.12 = **0.56** ⇒ F = 0.028。
测试仍以**暴力真值表**为锚(独立于任何手算);引擎 / 真值表 / 闭式三方一致。
这正是"手算多重容斥易错,锚点必须机器对拍"的实证——连本规格初稿都错了。

## 4 · API 与兼容

- 引擎:`fault_tree_frequency(model, ft, cutoff=0.0, method="sum"|"exact")`;
  返回新增 `"method"`;exact 另附 `"by_initiator": [{initiator, rate,
  enabling_probability, frequency}]`(降序)。`cutsets` 列表两模式同形
  (逐割集 λΠq,溯源用;exact 下 Σcutsets ≥ 头条,不再等于——响应里并存即披露)。
- **默认 `sum` 不变**(行业口径 + 现有存档/测试零扰动);exact 为增强。
- 头条与 by_initiator 基于**全部**最小化割集(先校验一频率规则,与 cutoff 无关);
  cutoff 只过滤展示的 cutsets 列表(既有语义)。
- 后端:`FtFrequencyRequest.method`(默认 sum,枚举校验);响应透传。前端 UI 开关
  留作后续小改(账本记 chip),本批不动前端。
- 每初因析取 BDD 的变量序:该初因使能变量名排序(集合小,序只影响规模不影响正确性)。
