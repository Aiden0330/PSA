1摘要与定位

本工具是面向储能电站(BESS)锂离子电池热失控的概率安全评估 / 定量风险评估 (PSA/QRA)全栈应用:后端以精确 ROBDD 为定量内核对标核工业商用软件 RiskSpectrum,前端提供画布优先的 下一代分析工作台,并以 AI 辅助 ETA/FTA 自动生成为旗舰能力。评审可追溯性是产品特性而非 文书负担——每一份报告中的每一个数字都能回溯到确切的模型版本、引擎版本、分析设置与数据条目出处。

产品由三根支柱构成:

  • RiskSpectrum 对标后端 —— 精确 BDD 顶事件概率、ZBDD/MOCUS 最小割集、 NUREG/CR-5485 全套 CCF 模型(β/MGL/α/φ,含错峰检验)、边界条件集、割集后处理规则、 重要度(B/FV/RAW/RRW/DIM)、蒙特卡洛不确定性、Open-PSA MEF XML 互换。其中 事件树成功分支的精确否定超越 RiskSpectrum 的 delete-term 近似(§4.3)。
  • 证据链版本库与评审签发 —— 保存即内容寻址版本(SHA-256 幂等),分析即自动钉扎 「分析案例」,报告页脚携带 分析案例 # · 版本哈希 · 引擎版本,审计日志只增不改 (SQLite 触发器强制,§4.11);评审/签发状态机 + 三角色本地认证把"谁在何时批准了哪个版本" 变成数据库物理事实(§4.14),多项目组合总览只呈现已钉扎的数字(§5.4)。
  • AI 辅助建模 —— 基于参考库检索接地的草案生成、确定性校验-修复环 (schema → 域 lint → 引擎试运行)、逐元素幽灵差异接受(ghost-diff)、金例评测门。 所有 AI 产物强制携带「AI 草案,待人工审核」溯源并默认 D 级置信(§4.12)。

3.3两者协同与 BESS 语境

完整的 QRA 是"ETA 定骨架、FTA 供血肉"的组合(bow-tie 视角:左半 FTA 解释初因, 右半 ETA 展开后果):

  • 屏障挂树:事件树中每道功能事件的失败概率可由一棵挂载故障树的顶事件概率给出 ——BESS 场景如「离气探测联动」= OR(传感失效, 逻辑失效, 执行失效) 再叠加共因;
  • 共享事件是常态而非例外:多道屏障共用同一供电、同一 BMS、同一传感器时, 分支概率不再独立,图 4 的积式失效——必须在合并布尔模型上精确量化(§4.3 的 0.109 锚点即此);
  • 初因也可建树:初因频率可由"频率型故障树"合成(每割集恰一个频率事件, §4.13),与手动输入并列为两条通道;
  • 尺度语境:BESS 模型跨电芯→模组→簇→舱四级,失效率单位随级别变化 (/cell·yr 与 /unit·yr 绝不静默换算,§7);后果级 C1(单体排气)到 C5(爆燃+毒气) 对应中电联严重度 0–IV(表 10)。

4算法详解

定量内核的设计原则:能精确就不近似。顶事件概率与序列频率走 BDD 精确通道; 割集/截断/REA/MCUB 仅作为大模型工程近似与后处理语义存在,且永不污染精确通道。每个算法的公式来源、 实现位置与数值锚点在各小节标注。

4.1ROBDD 精确概率内核

故障树先归一化为 PDAG(命题有向无环图:AND/OR/NOT/XOR/ATLEAST/NULL 门 + 基本事件 + house 常量), 经环检测、常量传播与同型门合并后,以固定变量序编译为约简有序二叉决策图(ROBDD)。 内核为自研纯 Python 实现(psaengine/bdd/kernel.py),两条约简规则:冗余节点消除 (hi = lo 时返回子节点)与哈希共享(unique table),保证任一布尔函数在固定 变量序下有唯一规范型——这是"同模型必同结果"的结构性保证。

刻意不用补边(complement edges)。带补边的 BDD 更省节点,但会使遍历协议与第三方 后端(CUDD)的语义对齐复杂化,并成为难以审计的错误源——本项目在 CUDD 适配器上曾实测到补边标记 在余因子操作中丢失导致非相干函数(含 NOT/XOR/成功分支)结果被破坏的缺陷,靠对拍测试锁定修复。 规范型的可解释性优先于节点数,是面向监管工具的取舍。

所有布尔运算统一经 ITE(if-then-else)算子实现,Shannon 展开逐层递归并记忆化:

(4-1) ite(f,g,h) = f·g + ¬f·h = ⟨v, ite(fv,gv,hv), ite(f¬v,g¬v,h¬v)⟩, v = min top-var

其中 AND(f,g)=ite(f,g,0)、OR=ite(f,1,g)、 NOT=ite(f,0,1);k/n 表决门(ATLEAST)以 ITE 递归 rec(i,need)=ite(xi, rec(i+1,need−1), rec(i+1,need)) 构造,精确处理门下挂门。

精确概率沿 BDD 做单遍 Shannon 递归(实现为显式栈后序遍历,规避 Python 递归深度上限; 万级事件深图实测无栈溢出,基准 24 例逐位不变):

(4-2) P(f) = qv·P(fhi) + (1−qv)·P(flo),   P(⊤)=1, P(⊥)=0

该式对任意相干/非相干结构给出数学精确的顶事件概率——无稀有事件假设、无 MCUB 上界、 无截断误差。这正是与以 MCS 为一等公民的商用工具的根本差异(§8)。

变量序采用 DFLM(depth-first left-most)启发式:按故障树深度优先遍历首次出现的顺序 排定基本事件——对手工构建的工程树,这一顺序天然把结构相关的事件排相邻,实测在基准语料上无一例爆炸。 BDD 变量序为 NP 困难问题,内核不做动态重排;规模换挡的答案是后端切换: make_manager(order, backend) 工厂在纯 Python(数百事件舒适区)、dd.autoref (验证用)与 dd.cudd(CUDD,万级事件,macOS arm64 编译实证)间共享同一遍历协议 (is_terminal/top_var_index/cofactor/var_name),量化代码后端无关。

4.2最小割集、截断与工程近似

割集提取走 BDD→ZBDD 路线:枚举 BDD 中使函数为真的正文字路径得到候选集族, 转入零压缩决策图(ZBDD)做吸收律最小化(minimize),得到全部最小割集; 同时提供教科书 MOCUS(自顶向下门展开)作为交叉验证器——性质测试断言两法在随机树上 集族相等。非相干结构(含 NOT/XOR/成功逻辑)下"最小割集"不再良定义,内核提供素蕴涵项 (prime implicants)替代(§4.10)。

截断按概率阈值与阶数双准则,并给出截断误差上界:被丢弃割集的概率和 ΔPk = Σ丢弃 P(Ci) 随结果一并报告——用户看到的 永远是"值 + 该值可信到什么程度"。两个经典 MCS 概率近似仅在后处理语义下使用(§4.8):

(4-3) REA:  P ≈ Σi P(Ci)     MCUB:  P ≈ 1 − ∏i (1 − P(Ci))

4.3事件树精确量化与成功分支精确否定

事件树各功能事件(屏障)可直接给 PFD,或链接一棵故障树。量化时把全部链接故障树合并进同一个 PDAG 与同一个 BDD 管理器,每个屏障得到自己的顶 BDD gi; 序列表达式按路径逐屏障取"失效 = gi / 成功 = ¬gi"做 AND:

(4-4) P(seq) = P( ⋀i∈失效 gi ∧ ⋀j∈成功 ¬gj ),  freq(seq) = fIE · P(seq)

因为所有 g 建在同一管理器上,跨屏障共享的基本事件(含 CCF 展开产生的 共因事件)在成功与失效分支间自动保持一致——成功分支的否定是布尔精确的,而非 RiskSpectrum/SAPHIRE 系的 delete-term 割集删除近似。守护测试锁定的数值锚:两屏障均为 OR(S, Xi)、共享事件 qS=0.1、 独立事件 qX=0.1(各顶值 0.19)时,双失效序列 LL 的精确概率为

(4-5) P(F₁∧F₂) = qS + (1−qS)·qX₁qX₂ = 0.1 + 0.9×0.01 = 0.109  ≠  0.19² = 0.0361(独立乘积,低估 3 倍)

前端画布提供"积式实时"预览(独立乘积,毫秒级反馈),「引擎精确量化」按钮走式(4-4);两者数值分歧时 界面以 ▶ 标记提醒——快速反馈与精确真值各司其职,绝不混淆。事件树支持有序可跳过分支 不变式:分支判定屏障必须按功能事件表顺序出现、允许跳过(子集路径),该契约由测试守护并与引擎请求形状 绑定。McMicken 等模板的屏障口径统一为"TR 已触发,该屏障能否阻止升级到下一后果级"。

RRWP / P(f|x_i=0)风险降低当量:假设完美,风险缩小几倍(改造上限)
DIMiB_i·q_i / Σ_j B_j·q_j微分重要度:小扰动下的归一化分摊

事件树屏障级用扰动法:把功能事件顶 BDD 强制为常量(gi:=⊤/⊥), 按后果类计算 FV=(R−Rwork)/R 与 RAW=Rfail/R。强制的是屏障顶而非其底事件——共享底事件下其他屏障 不受污染。注意良性后果(需屏障成功才到达,如 C1)FV 可为负、RAW 可 <1,属正常语义并在界面注明。

4.6不确定性分析(蒙特卡洛)

参数不确定性以分布描述(对数正态以中位数+误差因子 EF 参数化,另支持正态/均匀/Beta)。 对数正态抽样 σ = ln(EF)/1.645(EF 定义为 p95/p50)。共享底事件每次 迭代只抽一次——跨屏障/跨序列的状态知识相关性(state-of-knowledge correlation)自动保持, 这在 MCS 近似框架里往往被丢失。BDD 建一次、每次迭代仅重算式(4-2)概率,N=1000 默认秒级。 输出各后果类 C1–C5 的 p05/p50/p95 分位带 + 点估计;龙卷风图给出各参数对输出方差的排序。 不确定性运行与报告一样自动钉扎为分析案例(settings 含 samples/seed/EF,结果可复现)。

4.7边界条件与 house 事件

house 事件是取值恒真/恒假的常量事件,用于表达运行工况(检修、旁路、季节配置)。归一化阶段做 常量传播(OR 含真→真;AND 含假→假;否则剔除常量参数),BDD 编译前逻辑已化简。 边界条件集是命名的 house 状态字典,可随模型定义、按名引用;显式 house_states 覆盖命名集(逐键)。三条纪律:覆盖只作用于 PDAG 副本 (模型本体不可被分析改写——审计前提);未知 id 或指向非 house 节点响亮报 400(静默忽略会让边界条件 悄悄失效);FTA/ETA/不确定性/重要度全通道接受同一组参数。

4.8割集后处理规则

对标 RiskSpectrum 的 MCS 后处理语义,三类规则:互斥组(割集同含组内 ≥2 成员→删, 表达互斥维修态)、删除规则(割集 ⊇ 指定事件集→删)、恢复规则 (割集 ⊇ 触发集→追加恢复事件,概率相乘、阶+1,幂等不重复追加)。设计边界:规则只作用于 提取出的 MCS 列表,精确 BDD 概率通道不受任何影响——处理后列表以式(4-3)REA/MCUB 给出 MCS 级估计,与精确顶值在界面/报告中分列展示,该不变式由 API 测试直接断言。

4.9现场贝叶斯更新(Beta-二项)

把现场检验数据(需求次数 N、失败次数 k)融合进屏障 PFD。先验两种:以当前 PFD 为均值、等效样本量 n₀ 的 Beta(α₀=p·n₀, β₀=(1−p)·n₀),或无信息 Jeffreys (α₀=β₀=½)。共轭后验:

(4-7) p | N,k ~ Beta(α₀+k, β₀+N−k),  E[p] = α₀+kα₀+β₀+N,   p95 = Beta 分位数

界面提供「采用后验均值 / 采用 95% 上限」两种保守度;采用即写入 PFD、置信升 A、 并自动生成证据链文本(N、k、先验、日期)。这是内置库 C/D 级数据向项目 A 级演进的规范路径。

4.10模块化与素蕴涵项

模块化(Dutuit–Rauzy 线性时间算法[7]) 识别独立子树,子树概率可独立求值后作为超级事件回代——大树的分治通道。素蕴涵项 面向非相干函数:含否定逻辑时以 PI 取代 MCS 的语义(RiskSpectrum 不提供,本工具作为超集能力保留)。

4.11内容寻址版本库与审计

存储为单文件 SQLite(WAL,零外部依赖)四表:projects / versions / audit_log / analysis_cases (+ ai_drafts)。核心机制:

  • 确定性身份:实体 UUID = uuid5(项目命名空间, 实体路径) —— 同内容必同 ID, 是幂等与 diff 的前提;
  • 内容哈希:规范 JSON(键排序、紧凑、剥离易变时间戳)取 SHA-256; 保存即版本、同哈希幂等返回既有版本,父链成历史;
  • append-only 审计:代码层无改写路径,数据库层 BEFORE UPDATE/DELETE 触发器 RAISE(ABORT) 双保险,属性测试直接以裸 SQL 篡改并断言被拒;
  • 分析案例:报告/不确定性/重要度运行自动钉扎 —— 绑定版本 id、引擎版本、完整设置与 结果,报告产物再回写 sha256;
  • 模型对比:两版本的规范文档按 UUID 对齐,输出 added/removed/changed(含参数值 前后)——对标 RiskSpectrum Model Compare,前端报告页内置对比视图。

4.12AI 生成管线(ADR-3)

4.13初因事件故障树 → 频率通道

初因事件的量纲是频率(/yr),不是概率——把初因树喂给概率端点会产出 无量纲数再错标为 /yr(OR 门按 1−Π(1−q) 封顶 1、AND 门得 1/yr² 之类的量纲灾难)。本工具为此 建有独立的频率量化通道,采用与 RiskSpectrum / SAPHIRE / CAFTA 一致的 initiator–enabler 约定(Isograph FaultTree+ 亦提供同类初因-使能分析 [21]):每个最小割集恰好包含一个 频率型事件(initiator,λ /yr),其余为使能条件(enabler,无量纲概率 q):

(4-8) FIE = Σk∈MCS λk · Πe∈k qe   [/yr]

频率是计数强度,互斥割集的并直接求和(绝不做 1−Π(1−·));共享 使能事件跨割集时该式仍精确,共享初因事件时为保守上界 (非稀有区间无界,文档化)。护栏全部"响亮失败":

  • 任一割集含 0 或 ≥2 个频率事件 → FrequencyRuleError(400,中文 detail 点名割集);
  • 非相干门(NOT/XOR)在规范化图上直接拒绝——静默错数比报错危险(评审 round-1 F1);
  • 双向量纲护栏:频率参数进概率语境即 raise,负 λ / 负时间参数在源头拒绝;
  • 前端频率模式:量纲切换、频率不钳位 ≤1、IE 树与屏障树共享基本事件的独立性 lint(双侧编辑路径均拦截并解释)。

初因由此获得手动输入 / 频率型故障树两条并列通道;种子树 = 单频率事件 = 当前手动值,迁移零意外(预览实测 0.004 逐位不变)。该通道经 engine-reviewer 两轮对抗审查 (round-1 六项发现全修,round-2 PASS),规格含已知局限清单。

4.14评审签发与多用户认证

面向监管的"谁在何时批准了哪个版本"在本工具是数据库物理事实,不是流程约定。 两层机制:

  • 评审状态机(台账签发式):草稿(无评审行)→ 送审中 → 已签发(终态)/ 退回(须填理由,理由即证据)。数据库层双保险: 已签发行 BEFORE UPDATE/DELETE 触发器直接 ABORT;部分唯一索引保证每项目至多一行在审。 签发写入签发人、时刻、版本哈希与角色快照(授权依据可从只增链重建,不依赖可变账户表);
  • 导出门 = 内容寻址幂等:报告导出自动钉扎的版本若与已签发版本内容逐字节一致 (同哈希),页脚落签发行;任何未保存改动都是新哈希 → 自动成为「工作稿 — 未经签发」。 无需引入"冻结"概念,不可伪造盖章是存储层性质;
  • 认证为部署开关:PSA_AUTH=off(默认)单机离线零摩擦——这是最高 不变式;local 模式启用本地账户:argon2id 口令(RFC 9106 默认参数)、会话令牌 散列落库(库文件泄露 ≠ 会话劫持)、12 h TTL 过半滑动续期、未知用户走等时垫片 (枚举防御);三角色 analyst / reviewer / admin 路由守卫(分析-评审职责分离), 保存走乐观并发(基线哈希不符 → 409 冲突对话,绝不静默覆盖);每条审计行携带 auth:off|local 标记,OS 用户行与认证账户行在同一追踪链中可区分。

5.4多项目与组合总览

项目树支持同时打开多个项目:非活动项目整槽停放(文档 + 撤销历史 + 派生缓存 + 身份 + FMEA),任一时刻每个项目只存在于一处——跨项目串染按溯源违规级缺陷对待,由结构 + 13 条 锁测 + 独立对抗审查三重保障(异步保存期间切换项目,身份写回仍精确落在发起槽)。

「多项目组合总览」的证据链纪律:

  • 风险数字只取各项目最近一次已钉扎分析案例(案例 # · 版本哈希 · 场景随行显示), 绝不现算;无案例项目显示「未量化」,不补零冒充;
  • 案例钉在旧版本上时,行内亮琥珀徽章「数字非当前版本」——不要求读者肉眼比对哈希;
  • 累计列名即公式「C3+C4+C5 /yr」(后果类别口径;与单项目页"≥III 累计"=C4+C5 的危险等级口径 刻意区分),口径脚注为可见文字,截图不丢;
  • 矩阵落格与最劣格由后端 risk_placement 给定,阈值与单项目报告矩阵同源 (前后端各有一张 25 格金表互锁防漂移);对数条形显式标注「对数刻度,以数值为准」;
  • 评审队列按挂起评审行过滤(送审后又存新版的项目不会从队列消失, 标「已有更新版本」),点「前往报告页」直达该项目报告页。
口径边界。每个案例覆盖导出/运行当时的单棵事件树(场景), 组合总览据此比较的是"各项目最近钉扎场景",非项目全部 ETA 之和——页脚已披露; 按勾选集合并导出的"聚合范围钉扎"列于路线图(§11)。

5.5AI 建模助手使用指南

前置:后端环境变量 PSA_AI_ENABLED=1 + ANTHROPIC_API_KEY (离线演示可用 PSA_LLM_PROVIDER=fake);未启用时按钮给出明确提示而非静默失败。 入口:事件树页工具条「AI 建模助手」。

你需要提供的输入(与 §8.4 的 SOTA 输入需求对照,本工具走"轻输入 + 强校验"路线):

  • 一句话建模目标(自然语言,中文即可)——这是唯一必填项。 好目标 = 场景 + 关注点:「电池舱液冷泄漏导致外短,重点关注探测与灭火两道屏障」优于「帮我建个模型」;
  • 模式四选一:new_eta 新建事件树 / complete_eta 补全当前树 / fta_for_barrier 为选定屏障生成故障树(需先选屏障)/ standalone_fta 独立故障树;
  • 其余上下文自动携带:当前项目载荷、活动 ETA、参考库压缩摘要——AI 检索 search_reference_library 为数值找出处,不允许编造。

生成 → 审阅 → 应用:草案先过确定性校验门(schema 严格校验 → 域 lint → 引擎试运行,不可量化的结构直接打回,≤3 轮自动修复);到达后以 幽灵差异叠加在画布上——逐元素勾选接受/拒绝(拒绝的屏障整链正确折叠), 「应用」才写入文档并落审计回执。三条铁律:数值必须带 library_ref 或显式标注 ungrounded;AI 产物强制 D 级置信 +「AI 草案,待人工审核」溯源(自评 A/B = 校验错误); 草案永不直接落库,人是唯一提交者。切换项目会清空未应用草案(草案是项目上下文的产物)。

排错。400「PSA_AI_ENABLED」= 未开开关;「校验未通过(N 轮)」= 结构反复 不可量化,换更具体的目标重试;生成很慢 = 正常(检索 + 试运行两道门);金例评测 python -m backend.ai_eval submit 用于换模型/提示词前的回归把关。

6.1α 因子 CCF 手算(2oo3 传感通道)

三取二气体探测,单通道 Qt=1×10⁻²,α=(0.95, 0.03, 0.02),非错峰。 αt=1×0.95+2×0.03+3×0.02=1.07:

Q₁ = (0.95/1.07)·10⁻² = 8.879×10⁻³  ·  Q₂ = (2/2)·(0.03/1.07)·10⁻² = 2.804×10⁻⁴  ·  Q₃ = 3·(0.02/1.07)·10⁻² = 5.607×10⁻⁴

8文献综述

8.1方法学基础:从割集到决策图

故障树定量的第一代方法围绕最小割集:Fussell 的 MOCUS 自顶向下展开[3] 确立了 MCS 作为工程语言的地位,NUREG-0492《Fault Tree Handbook》[4] 将其规范化;概率则依赖稀有事件/最小割集上界近似。范式转移来自 Bryant 的 ROBDD 规范型 [1]与 Rauzy 把 BDD 引入故障树 [2]:布尔函数获得唯一表示,顶事件概率一次遍历精确可得, 非相干逻辑(素蕴涵项)也纳入统一框架。Dutuit–Rauzy 线性模块化[7] 与后续 ZBDD 割集技术补齐了大模型工程通道;近年形式化方法社区的再评估(“BDDs Strike Back” [8])确认 BDD 在静态故障树上仍是精度/性能的标杆。 商用侧,RiskSpectrum 的 MCS-BDD 混合算法(PSAM 系列论文[9]) 代表"以 MCS 为主、BDD 校准"的路线;本工具反其道:BDD 为一等公民,MCS 为工程视图。 互操作层面,Open-PSA 模型交换格式(MEF)[10]是 跨工具语料与基准(XFTA/SCRAM/SAPHSOLVE 对比研究[14])的通用底座。

共因失效参数模型的权威源是 NUREG/CR-5485[5] (β/MGL/α/φ,错峰与非错峰检验方案)——本工具公式与 SCRAM 实现逐式核对(§4.4)。

8.2BESS 安全域

事实基线:EPRI 储能失效事件数据库及其 2024 白皮书[12] (81 起事件、26 起可归因;单位容量失效率 2018→2025 下降约 97–99%;根因重心从电芯缺陷转向 集成与运行阶段缺口,与 PNNL/TWAICE 联合分析一致)。事故解剖学的标杆是 DNV 的 McMicken 技术分析[11](串级五重屏障缺失:热障、灭火剂 对 TR 无效、无泄爆、开门引气)——本工具将其编码为可反事实检验的预置模板(§6.2)。2025-01 Moss Landing 事件再次抬升监管关注度。标准框架:UL 9540A(单元级蔓延测试)、NFPA 855/68/69(选址/泄爆/防爆)、 IEC 62933-5-2 与 62619(系统/电芯安全)、GB/T 36276 等;探测窗口的实证研究(Sandia 离气/VOC 传感, JES 2024[13])支撑预警屏障 PFD 取值。学术侧 2024–25 的代表方向是 FTA/ETA 与模糊贝叶斯网络、多尺度风险框架的组合 [15]——共同短板是数据分级与可追溯性弱,恰是本工具 以证据链机制正面回应的问题。

8.3AI × PRA

生成式模型进入 PRA 的文献仍在早期:综述与立场论文(如 arXiv:2406.01133 [16])划定"受控使用"条件;FTA 副驾驶研究 [17]一致结论是 LLM 提议、人类裁决 ——不让模型直接产出可信数字。基准(JFTA-Bench)与风险分析期刊的实证(LLM 做发散性 FMEA 头脑风暴有效、 数值判断不可靠)同向。本工具的 ADR-3 管线把这些原则工程化:检索接地强制数值有出处、确定性校验门 (含引擎试运行)把关结构可算性、幽灵差异保证人是唯一提交者、金例评测门管控模型/提示词升级—— 据我们所知,这是 BESS QRA 场景下首个把「AI 草案不可信」作为架构前提而非免责声明的实现。
