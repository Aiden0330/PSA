# 预警屏障有效性数据细化

## 1. 分型维度表

| 类型              | 典型条目 id                | 核心特征                                      | 建议起始定级 |
|-----------------|--------------------------|---------------------------------------------|------------|
| AI 数据驱动预警   | `warn-ai`                | 端到端模型;召回率依赖训练集与覆盖场景           | C(测评验证后升级) |
| 机理阈值预警      | `warn-threshold`、`warn-high-temp` | 温度/电压/SOC 阈值;易整定误差;漏报主因 | D          |
| 气体单参量 H₂    | `warn-gas-h2`            | 热失控临界前 <1 min 出现;提前量短;单参量漏报率高 | D          |
| 气体单参量 CO    | `warn-gas`(已有)         | 与 H₂ 类似提前量;单一气体浓度阈值             | D          |
| 气体单参量 VOC   | `warn-offgas-voc`、`warn-gas-voc-early` | 电解液蒸气;提前量 2–30 min;传感器种类多 | D/C        |
| 多参量联动预警    | `warn-tr-multi`          | 气/烟/压联动;漏报率低于单参量,提前量中等       | C          |

**选型原则:**提前量(影响操作员响应窗口)> 精确率 × 召回率 > 安装密度。多参量联动在条件允许时优先。

## 2. 口径规范

**核心原则:successProb 存储的是事件级召回率(PFD = 1 − successProb),不是样本级准确率。**

| 指标                  | 说明                                              | 是否直接入库 |
|---------------------|--------------------------------------------------|------------|
| 事件级召回率           | 在一次真实热失控事件中,预警系统成功触发的概率         | 是,直接作 successProb |
| 样本级精确率/F1        | 基于时序切片的分类指标;受采样率与负样本比例强烈影响   | 否,不直接入库 |
| 误报率(FPR)          | 每年无故报警次数/次数率                             | 否,记入 source.note |
| 提前量(lead time)    | 预警触发到临界事件的时间中位数或最小值               | 否,记入 source.note |

**note 推荐格式:**
```
事件级口径;提前量中位数 X min;误报率约 Y 次/年(超过阈值须评估运营成本);来源:XXX
```

## 3. 与 P12 测评管道的对接流程

P12 测评管道(`src/data/evalPipeline.ts`)将现场 CSV 测试记录聚合为贝叶斯更新结果,最终生成 A 级用户层条目。

### 3.1 入口:EVAL_CSV_HEADER

```ts
// src/data/evalPipeline.ts
export const EVAL_CSV_HEADER = ['barrierId', 'kind', 'demands', 'failures', 'date', 'citation', 'note'] as const;
```

字段说明:
- `barrierId`:与 `BARRIER_LIBRARY` 中 `id` 对应(如 `warn-gas-h2`)
- `kind`:试验 | 运行(区分台架测试与现场统计)
- `demands`:测试/运行中的总需求次数
- `failures`:漏报/失效次数
- `date`:记录日期(ISO 8601)
- `citation`:证据出处(试验报告/台账编号)
- `note`:可选备注

### 3.2 处理流程:applyEvalRecords

```
CSV → 原子校验(任一行非法整体拒绝) → 按 barrierId 聚合
  → 先验 = 当前内置条目 PFD(经 toPrecision(12) 归一)
  → LOPA n₀ / Jeffreys 兜底
  → Beta 二项后验:mean | upper(单侧 90%/95%)
  → 输出 A 级用户层条目
```

校验规则:
- `n_demands` 为非负整数,`n_failures` ≤ `n_demands`
- `kind` 只允许"试验"或"运行"

### 3.3 节点级贝叶斯更新(P5,bayes.ts)

若测试数据不足以走完整管道,可在节点面板直接录入"需求/失败"次数:
- 触发:`src/core/bayes.ts` Beta 二项共轭更新
- 先验:LOPA 当前值(可调 n₀)/ Jeffreys
- 输出:后验均值与 90%/95% 单侧上限
- 注意:挂 FaultTree 节点禁用贝叶斯更新

### 3.4 升级结果

| 操作                | grade 变化 | 数据层      |
|-------------------|----------|------------|
| 直接引用公开统计    | C        | builtin    |
| 现场测试<22次需求  | D        | builtin 或用户层 |
| 节点贝叶斯更新      | A        | 用户层      |
| 测评管道(evalPipeline) | A    | 用户层      |

**黄金锚点:**`betaQuantile(0.9, 1, 22) ≈ 0.0994` — 22 次需求零漏报可以 90% 置信验证 PFD₁ ≤ 0.1(对应 C 级 warn-ai 条目的验证门槛)。

## 4. 误报率治理

**误报不进 PFD**,但须在 `source.note` 中记录,理由:

1. ETA 模型中 PFD = 1 − P(成功预警 | 真实热失控事件),误报是假阳性与真热失控无关
2. 过高误报会导致操作员忽视报警(cry wolf 效应),间接降低实际召回率——这是系统集成层面的风险,需在运营规程而非 PFD 数值中管控

**note 推荐写法:**
```
事件级召回率 X%;历史误报率约 Y 次/年,超过 Z 次/年时运营成本显著,
须评估传感器阈值重整定或联动逻辑优化
```

## 6. 示范条目指引

builtin 库已包含以下 P16 预警分型示范条目:

| id                  | successProb | grade | 类型           | 说明                     |
|---------------------|-------------|-------|----------------|--------------------------|
| `warn-gas-h2`       | 0.93        | D     | 气体单参量 H₂  | 提前量 <1 min,漏报率示例值 |
| `warn-gas-voc-early`| 0.95        | C     | 气体单参量 VOC | 提前量约 8.5 min,实测数据  |

与已有条目的区分:
- `warn-gas-h2` vs `warn-gas`(0.93/D):前者明确单参量 H₂,后者为"H₂/CO 混合"引用;分型示范条目更明确气体种类
- `warn-gas-voc-early` vs `warn-offgas-voc`(0.95/D):前者来源升级为 C 级(Sandia 实测验证),后者为更宽泛 D 级引用

新增预警条目时,参照示范条目写明分型、口径、提前量信息。

**P22 扩展(2026-06-22):**已补按前驱档位分型——`warn-consistency-slow`(慢前驱,一致性劣化/自放电,周–月提前量,0.85/D)、`warn-isc-progressive`(中前驱,渐发内短路,IC 曲线畸变,小时–天,0.9/D),来源 SOTIF 综述表 2;与气体快前驱(H₂/VOC/多参量)互补,均事件级召回口径。
