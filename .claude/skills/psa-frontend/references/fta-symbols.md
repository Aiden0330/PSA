# 标准 FTA 符号规范（fta-symbols）

故障树符号是行业通用语言（源自 NUREG-0492 故障树手册），**不可自创图形**，否则核电/可靠性领域用户无法识读。本文给出每种符号的形状、语义、何时用，以及 SVG 绘制要点。配套实现见 `assets/FtaNodes.tsx`。

## 一、事件符号

| 符号 | 名称 | 语义 | 绘制要点 |
|---|---|---|---|
| ○ 圆 | 基本事件 basic event | 不再展开的底层失效（有失效率/概率） | 正圆，下方接文字标签框 |
| ◇ 菱形 | 未发展事件 undeveloped event | 因信息/意义不足而不再展开的事件 | 菱形（四边等长） |
| ⌂ 房子形 | 房屋事件 house event | 布尔开关（TRUE/FALSE），用于切换模型构型/边界条件 | 矩形上加三角屋顶 |
| ⬭ 椭圆 | 条件事件 conditioning event | 施加于门（尤其 INHIBIT/PRIORITY）的条件 | 横椭圆 |
| ▭ 矩形 | 中间事件 intermediate event | 门的输出事件（由下层门/事件经逻辑产生） | 矩形文字框，通常画在门的正上方或与门合并显示 |

约定：事件的文字标签（id + 描述）统一放在符号下方的矩形里；基本事件可在符号内或旁叠加当前概率值（结果态）。

## 二、门符号

| 符号 | 名称 | 语义 | 绘制要点 |
|---|---|---|---|
| AND（平底拱形/盾形） | 与门 | 所有输入同时发生才输出 | 底边平直，顶部半圆拱起（D 形竖放） |
| OR（曲底盾形） | 或门 | 任一输入发生即输出 | 底边内凹弧线，两侧上收成尖顶 |
| ATLEAST k/n（OR 形 + 标注 k/n） | 表决门 voting / k-out-of-n | n 个输入中至少 k 个发生即输出 | 用 OR 形，门体内或旁标注 "k/n"（如 2/3） |
| XOR（OR 形 + 内部异或线） | 异或门 | 恰好一个输入发生才输出 | OR 形底部加一条贯穿短线 |
| INHIBIT（六边形） | 抑制门 | 条件满足时输入才传递（配条件事件椭圆） | 正六边形 |
| PRIORITY-AND（AND 形 + 内部弧） | 优先与门 | 输入按特定先后顺序发生才输出 | AND 形内加一道弧表示时序 |
| NOT（OR/AND + 取反小圆） | 非门 | 逻辑取反（非相干树用） | 门输出端加一个小空心圆 |

BESS 场景最常用 AND/OR/表决三种；NOT/XOR 仅在非相干分析时出现；INHIBIT/PRIORITY 在需要条件或时序时用。

## 三、转移符号

| 符号 | 名称 | 语义 |
|---|---|---|
| △ 三角形（向内/向外） | 转移门 transfer in/out | 把大树拆到多"页"：transfer-out 表示此处内容在别页展开，transfer-in 表示这里是某 transfer-out 的接续 |

转移门是**大模型导航**的核心机制：用它把单棵巨树切成可读的多页/多模块。UI 上点击转移门应能跳转到对应页（配 breadcrumb 返回）。

## 四、SVG 绘制要点（配合 assets/FtaNodes.tsx）

- 每个节点是一个 React Flow 自定义节点：外层固定尺寸容器（如 80×64），内含一个 `<svg>` 画符号 + 一个标签区。
- 门的连接点（React Flow `Handle`）：输出在顶部中点（target，连向父），输入在底部（source，连向子）。注意故障树习惯顶事件在上、基本事件在下，父在上子在下，故"父用 target 顶、子用 source 底"。
- AND/OR 形状用 `<path>` 贝塞尔曲线绘制：
  - AND：`M0,H L0,h Q0,0 W/2,0 Q W,0 W,h L W,H Z`（底平、顶拱）。
  - OR：底边用二次曲线内凹，两侧上收尖顶。
- 表决门复用 OR 的 path，再在中心 `<text>` 叠加 "k/n"。
- 状态叠加：结果态时在符号角落用小字显示概率/频率；按重要度（FV/RAW）给符号描边或填充做热力着色（见 results-and-data.md）。
- 校验态：悬空/循环/缺参数的节点用红色描边 + 角标图标提示。

## 五、可读性与一致性

- 同一画布内门与事件尺寸统一；标签超长截断 + hover 全称。
- 颜色：默认中性（黑描边白填充）；仅用颜色表达**语义叠加**（割集高亮、重要度热力、校验错误），不要给符号本身上花色，以免与结果着色冲突。
- 缩小（语义缩放 LOD）时隐藏标签、只留符号轮廓；进一步缩小时子树合并为一个占位块。
