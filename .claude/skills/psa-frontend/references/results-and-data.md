## 1. 可靠性参数库 UI

逻辑-数据分离的落地面：故障树只放引用，真实数据集中在这里。
- **字段**：参数 id/名称、类型（概率 PFD / 失效率 λ / 频率 / MTTR / 测试间隔 τ / 任务时间）、数值、分布（lognormal + 误差因子 EF / gamma / beta）、来源（T-Book / NUREG-CR-6928 / OREDA / IEEE / LOPA…）、版本、适用性/标签、备注。
- **交互**：大表用 AG Grid（行列虚拟化，十万行级）；支持排序/过滤/分组、就地编辑、批量编辑（多选改同一字段）、导入/导出（CSV/Excel/JSON）。
- **共享引用**：一个参数被多个基本事件引用；改参数→所有引用处自动更新。UI 可显示"被 N 个事件引用"并可反查。
- **出处可溯**：每条参数带 source/date/适用性字段（储能数据稀疏，需贝叶斯更新与显式不确定性，出处尤其重要）。
- 配置见 `assets/ParamGrid.tsx`。

## 2. CCF 组管理

详见 interactions.md 第 7 节。要点：列表管理 CCCG、选模型（Alpha/MGL/Beta/Phi）+ 参数、框选事件入组、参数依据 NUREG/CR-5485、与参数库联动。

## 3. 最小割集（MCS）结果表

- 列：割集序号、包含的基本事件、阶数（size/order）、概率/频率、对顶事件的百分比贡献、累计贡献。
- 交互：按概率/频率排序、按阶数/事件过滤、搜索；行内用条形单元（data bar）直观表示贡献占比。
- 点选割集→图上回溯高亮（见 interactions.md 第 6 节）。
- 用 AG Grid（同参数库），大量割集时虚拟化必需。

## 4. 重要度可视化

- 指标：Fussell-Vesely、Birnbaum、RAW、RRW（按基本事件）。
- **龙卷风图（tornado）/横向条形**：按重要度排名展示 top-N 事件，最直观。用 ECharts 横向 bar，正负/高低用颜色区分。
- **树节点热力着色**：把 FV 或 RAW 值映射为故障树节点的填充/描边颜色（热力图），一眼看出风险驱动点。
- 排名表 + 图联动：点表格行高亮图上节点，反之亦然。
- option 构造见 `assets/importanceChart.ts`。

## 5. 不确定性 / 敏感性可视化

- 蒙特卡洛输出：直方图 / 核密度图 + 均值/中位数/5th/95th 百分位标注；用 ECharts。
- 敏感性：单参数扫描的龙卷风图（参数在上下界间变动对顶事件的影响幅度）。
- 误差棒：在重要度/概率条形上叠加置信区间。

## 6. 结果叠加到模型

- 量化后把概率/频率叠加显示在门与事件符号上（角标小字）。
- 热力着色：按重要度给节点上色（红=高风险驱动）。
- 割集回溯高亮（见 interactions.md 第 6 节）。
- 原则：结果着色与符号本身保持分离——符号用中性色，颜色专用于表达结果/状态，避免冲突。

## 7. 图表库选型

| 库 | 许可 | 适用 | 备注 |
|---|---|---|---|
| **Apache ECharts (6.x)** | Apache 2.0 | 仪表盘、龙卷风、直方图、热力、大数据集 | **首选**；声明式、性能好、Canvas 渲染；6.0 于 2025 发布，6.1.x 为 2026 最新 |
| **D3.js** | ISC/BSD | 高度定制、非标准图 | 灵活但开发成本高 |
| **Recharts / visx** | MIT | React 标准图 | SVG 渲染，万点级变慢 |
| **AntV G2/G2Plot** | MIT | 统计图表 | 与 X6 同生态 |
| **Plotly** | MIT | 科学图、3D | 体积较大 |

数据表（参数库、MCS 表）用 **AG Grid**（虚拟化、企业版需授权）或 TanStack Table（无头 MIT，需自配虚拟化）或 Glide Data Grid（Canvas，电子表格体验）。1000 行以上虚拟化成为必需。
