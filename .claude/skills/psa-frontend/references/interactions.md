## 1. 拖拽建模与连线

- **左侧符号调色板**（palette）陈列门与事件符号；拖放到画布生成节点（HTML5 DnD 或库内置）。React Flow 用 `onDrop` + `screenToFlowPosition` 落点。
- **连线**：从子节点底部 Handle 拖到父节点顶部 Handle 建立父子边；连线即时校验（不允许制造环、不允许基本事件有子、门必须有≥1 子）。
- **吸附**：落点吸附到网格或布局槽位；连线吸附到 Handle。
- **选择性粘贴陷阱**：复制子树粘贴时弹窗问"作为同一事件引用 / 作为新独立事件（自动重命名）"。同名即同事件，静默处理会引入/消除 CCF（Isograph 官方警告）。
- **就地编辑**：双击节点标签就地改 id/描述；右侧属性检查器（inspector）改类型、参数引用、门阶（k/n）。

## 2. 自动布局与重排

- 布局是纯函数 `(nodes, edges) => positionedNodes`，用 Dagre（`rankdir:'TB'` 顶向下）。编辑后触发一次重排。
- 增量友好：大树只重排受影响子树，避免整图跳动；或提供"重新布局"按钮让用户手动触发，保留其手工微调。
- 折叠的子树在布局时按一个占位节点计算尺寸。
- 实现见 `assets/useAutoLayout.ts`。

## 3. 大模型导航

从第一天规划，越晚补越痛：
- **Minimap/概览**：右下角缩略图（React Flow `<MiniMap/>`、X6/GoJS 内置）。
- **缩放/平移** + **语义缩放（LOD）**：缩小时隐藏标签、只画符号轮廓；再缩小子树合并为占位块。React Flow 监听 `zoom` 切换节点渲染细节。
- **子树折叠/展开**：门上加折叠按钮（GoJS TreeExpanderButton 同理），折叠后下挂子树隐藏并以徽标显示规模。
- **转移门分页**：用 transfer-in/out 把巨树切成多页/模块；点击转移门跳转目标页，顶部 breadcrumb 可返回。
- **搜索/过滤/高亮**：按 id/描述/参数搜索，命中节点高亮并自动平移居中；按类型/重要度过滤。

## 4. 实时校验高亮

编辑时即时标记，不等到量化才报错（CAFTA 内置语法/逻辑/循环/独立性检查）：
- 循环逻辑（环）、悬空节点（无父或门无子）、未定义参数的基本事件、门阶非法（k>n）。
- 出错节点红色描边 + 角标；侧栏列出问题清单可点击定位。

## 5. 事件树表格交互

事件树是**表格**不是自由画布（这是与故障树的根本区别）：
- **列 = 功能事件（顶事件/表头）**，按时序从左到右；**行 = 序列**。
- 每个功能事件处二叉分支：**成功向上、失败向下**（惯例 Yes/成功上、No/失败下）；每个分支点成功+失败概率之和必须为 1，UI 实时校验。
- **末列 = 后果/末态分箱**（BESS 用 C1–C5）+ 序列频率（= 始发频率 × 各分支概率连乘）。
- **链接到故障树**：功能事件的失败分支概率可链接到一棵故障树的顶门取值（小 ET/大 FT），也可直接挂一个基本事件/常量 PFD。点击表头可跳到对应故障树。
- **边界条件**：可对某功能事件下游施加边界条件，或经始发事件施加于整条序列。
- **序列枚举**：自动列出所有序列、其路径（各屏障成功/失败）、后果与频率，可排序/过滤。
- 实现骨架见 `assets/EventTreeTable.tsx`。

## 6. 割集回溯到树（CutSetTracer 式）

成熟工具的杀手锏，**必做**：
- 量化后得到最小割集（MCS）列表；点选某个割集，在故障树上高亮其包含的基本事件及从这些事件向上传播到顶事件的路径（边/门一并高亮）。
- 反向：点选树上某基本事件，列出包含它的所有割集。
- 配合 what-if：在割集结果上临时改某事件概率或设 TRUE/FALSE，免重算全部割集即看影响（CAFTA 割集编辑器思路）。
- 实现：store 里 results 持有 MCS（每个是 basicEventId 列表）；高亮 = 给相关节点/边打 `highlighted` 标记，节点组件据此改描边。

## 7. CCF 组管理 UI

- 列表式管理共因失效组（CCCG），每组：成员事件集 + 模型（Alpha 因子 / MGL / Beta 因子 / Phi）+ 对应参数（如 Alpha1…Alphak，且约束总和≤1）。
- 两种选成员方式：对话框多选事件；或在故障树图上**框选**事件→"加入 CCF 组"。
- 参数权威依据 NUREG/CR-5485。UI 要校验参数范围与归一。
- 与参数库联动：CCF 组引用的单元失效概率来自共享参数。

## 8. 模型差异、版本与协作

- **结构化图 diff**：按节点 id 匹配两个版本，标记新增/删除/修改（门类型变了、参数引用变了、子树增删）；并排双视图 + 着色（绿增/红删/黄改），仿 RiskSpectrum Model Compare。不要用文本 diff，要按图结构 diff。
- **版本/审计**：模型快照 + 变更历史 + 作者/时间 + 未审查变更标记；安全关键（ASME/ANS PRA 标准、监管）需可追溯审计日志与评审/批准流程。
- **实时协作（差异化优势）**：用 Yjs（CRDT）把 store 的模型字段做成共享类型，多人同时编辑自动合并；awareness 协议显示他人光标/选区/选中节点。撤销用 Yjs `UndoManager`（区分本地/远端）。
- 离线合并：Yjs 天然支持离线编辑后重连合并，无中心锁。
