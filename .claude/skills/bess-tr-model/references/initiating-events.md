# 初始事件(initiating-events)

按滥用类别分三大类,叠加"潜在制造缺陷"这一不依赖外部滥用的内因。事件树的初始事件(IE)从中选取。

## 1. 电气滥用(Electrical abuse)
- **内短路(ISC)**:潜在制造缺陷(金属异物、毛刺)、锂枝晶/异常锂金属沉积、隔膜失效。APS McMicken(2019)DNV GL 报告判定起源为单个电芯内短(疑异常锂金属沉积;LG/Exponent 持外部电弧异议)。
- **外短路、过充、过放、过流**。
- **BMS/传感失效、接触器/熔断器失效**:韩国 MOTIE 四大原因之一——地故障/短路保护不足、熔断器无法快速切断大浪涌致接触器灾难性失效、短路电流蔓延至母排引发舱内起火。
- **连接/接触故障**:松动母排、电弧故障。

## 2. 热滥用(Thermal abuse)
外部加热、高环境温度、**冷却/HVAC 失效**、邻近电芯传热(蔓延)。Victorian Big Battery(2021):液冷泄漏 → 功率电子电弧 → 热量将电芯推入热失控;故障单元已离线致监测/告警关闭。

## 3. 机械滥用(Mechanical abuse)
挤压、针刺/穿透、振动、跌落、壳体破损、**进水**。韩国 23 起事故中 18 起位于山区/沿海,大温差、高湿、粉尘/盐雾致冷凝与绝缘劣化。

## 4. 潜在制造缺陷(latent defect)
不依赖外部滥用,随时间/循环演化为内短。事件树中常作为"低频率、高后果"的独立 IE。

## 5. 按场景的触发频率(EPRI/PNNL/TWAICE 2024,基于 81 起入库、26 起可定根因)
- **无单一主导根因**;平衡系统(BOS:直流/交流接线、HVAC、消防)与控制是主要失效环节,电芯本身占比相对小。
- 按根因阶段:**集成/装配/施工≈36%、运行≈29%、设计≈21%、制造仅≈4%**。
- **72% 事故发生在施工、调试或运行头两年**。
- 失效率从 2018 约 9.2 起/GW 降至 2023 约 0.2 起/GW(降幅约 98%,第三方解读,待核验)。

## 6. 五类代表性 IE(供事件树)
1. 电芯内短(潜在缺陷/锂枝晶)— 低频高后果(McMicken 范式,可至 C5)
2. 液冷泄漏 → 电弧/外短 → 热滥用(Victorian Big Battery 范式)
3. 过充 / BMS 失效(SOC>95% 高危,韩国范式)
4. 外部火 / 邻舱热辐射(多舱蔓延)
5. 机械损伤 / 进水(沿海/山区环境,韩国范式)

> 建模提示:每个 IE 起一棵事件树或一条始发分支;频率绝对值数据稀缺,用 EPRI 数据库 + 生命周期相位校准,并在敏感性分析中覆盖根因归类的不确定性。
