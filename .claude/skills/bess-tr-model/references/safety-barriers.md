# 防护屏障(safety-barriers)

纵深防御四级。每级屏障阻断特定演化阶段——这正是事件树的分支节点。

## 1. 电芯级
安全阀(开阀泄压)、CID(电流切断装置)、PTC、陶瓷涂覆隔膜、化学体系(LFP 比 NMC 热稳定、释氧少、蔓延慢、峰温低)。
→ 阻断"压力/温升→破裂"与"自产热→热失控"。

## 2. 模组级
电芯间热障/隔热(气凝胶如 Aspen PyroThin、云母、膨胀型/陶瓷)、电芯间距、模组级熔断与泄气。
→ 阻断"电芯→电芯/电芯→模组"蔓延。McMicken 关键教训:电芯间缺热障导致级联热失控。

## 3. 电池簇/机架级
BMS(监测 V/T/电流/SOC、均衡、接触器跳闸)、气体探测、**离气探测(起火前早期)**、烟/热探测、热管理。
→ 阻断"触发→热失控"(BMS 切断)与"排气→烟→起火"(探测触发响应)。注意 UL 9540A 测试中 BMS/TMS 被禁用(代表最恶劣情形)。

## 4. 系统/集装箱级
灭火(气溶胶、细水雾、洁净剂 Novec 1230、水基)、**泄爆 NFPA 68 / 防爆 NFPA 69**、分舱、单元间距(NFPA 855 默认 ESS 间隔 3 ft/914mm,可由 UL 9540A 数据缩减)、紧急停机、HVAC、泄爆板。
→ 阻断"舱内可燃气积聚→爆燃"与"单舱火→多舱蔓延"。McMicken:Novec 1230 无法阻止热失控,且无排风致可燃气积聚,开门引气触发爆炸。

## 5. 六个标准分支节点(事件树表头,按链条顺序)
```
① 早期离气探测 + 联动(切断/通风/预警)?   ← 窗口最长,设为首分支
② BMS 切断 / 隔离?                          ← =传感∧逻辑∧接触器(可挂故障树)
③ 电芯间热障阻断蔓延?
④ 舱内泄爆 / 防爆动作?                      ← NFPA69 优先于 68
⑤ 舱间距阻断多舱蔓延?
⑥ 应急响应(避免开门引气)?                ← 显式人因屏障
```
每节点二叉:成功(上)=有效,失败(下)=升级一个后果等级。主动灭火等"启动但可能无效"的屏障用三结果分支(启动且有效 / 未启动 / 启动无效)。

## 6. 探测分层(时序)
离气最早(电解液 VOC)→ 烟(VESDA 吸气式)→ 热/火焰最晚。AI/ML 早期预警 + SOTIF(ISO 21448)针对传感与算法的预期功能安全。

## 7. 按场景的屏障集合
- **电网集装箱**:泄爆/防爆 + 单元间距主导;户外被动设计;气体灭火 + 水基。
- **户用**:室内 UL 9540A 强制;壳体泄压;空间小、邻近人员 → 探测与阻蔓延权重高。
- **数据中心 UPS**:多为 NMC(高功率密度)→ VESDA + 离气(Li-ion Tamer)+ 洁净剂,与机房消防联动。
